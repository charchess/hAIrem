# Story 23.2: Polyphonie Visuelle (Arbitration Glow)

**Status:** Done
**Epic:** 23 - L'Observatoire

## Story
**As a** User,
**I want** to see clearly which agent is speaking or reacting,
**So that** I don't get lost in a multi-agent conversation.

## Acceptance Criteria
1. **Speaking Signal Start:** When an agent starts generating a response, a `agent.speaking { speaking: true }` event is published on `system_stream`.
2. **Speaking Signal End:** When the response is complete (or on error), a `agent.speaking { speaking: false }` event is published — guaranteed via `finally`.
3. **Frontend Scale + Glow:** The active speaker's avatar scales to 1.05 + arbitration glow CSS class applied.
4. **Grayscale on others:** Non-speaking agents receive `grayscale(20%)` via CSS.

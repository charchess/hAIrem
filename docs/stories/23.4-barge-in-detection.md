# Story 23.4 — Détection du Barge-in

## Status: Done

## Goal

Permettre à l'utilisateur d'interrompre un agent en cours de parole via un événement `audio.barge_in`.

## Implementation

### `src/services/audio/speech_queue.py`
- `is_speaking: bool = False` — état TTS actif
- `current_speaker: str | None = None` — agent en cours de parole
- `set_speaking(agent_id)` — active l'état + mémorise l'agent
- `interrupt()` — vide la queue + remet `is_speaking=False`, `current_speaker=None`

### `src/models/hlink.py`
- `AUDIO_BARGE_IN = "audio.barge_in"` — type de message entrant
- `AGENT_INTERRUPTED = "agent.interrupted"` — type de réponse accusé

### `src/main.py` — `HaremOrchestrator`
- `self.speech_queue = SpeechQueue()` dans `__init__`
- Handler `audio.barge_in` dans `handle_message` :
  - Si `speech_queue.is_speaking` → appelle `interrupt()` + publie `agent.interrupted` sur `system_stream` avec `agent_id` de l'agent interrompu
  - Si pas en train de parler → ignoré silencieusement

### `src/features/home/wakeword/service.py`
- `emit_barge_in(speech_queue=None)` : publie `audio.barge_in` sur `system_stream`
  - Si `speech_queue` fourni → émet seulement si `speech_queue.is_speaking`
  - Gestion d'erreur gracieuse

## Tests TDD (RED → GREEN)

- `tests/test_barge_in.py` — 9 tests

**SpeechQueue :**
- `is_speaking` false par défaut
- `current_speaker` none par défaut
- `set_speaking(agent_id)` active les deux
- `interrupt()` remet les deux à zéro + vide queue

**Orchestrator :**
- `audio.barge_in` → `interrupt()` appelé → `is_speaking=False`
- `audio.barge_in` → `agent.interrupted` publié avec `agent_id` correct
- `audio.barge_in` ignoré si `is_speaking=False`

**WakewordService :**
- `emit_barge_in()` publie `audio.barge_in` sur `system_stream`
- `emit_barge_in(speech_queue=...)` n'émet pas si pas en train de parler
